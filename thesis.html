Curriculum-based Deep Reinforcement Learning for Home Robot Navigation with Natural Language Interaction

Master’s Thesis — Master’s Program in Computer Science
Graduate School of Science and Technology, Degree Programs in Systems and Information Engineering
University of Tsukuba · January 2025
Muhammad Angga Muttaqien · Advised by Prof. Akihisa Ohya
Research Profile | Google Scholar | GitHub

Overview

This research investigates how a home robot can learn to navigate household environments, interact with objects, and follow natural-language instructions within one learning framework. The central idea is to combine multi-modal deep reinforcement learning with curriculum learning, allowing the robot to acquire foundational skills before being exposed to increasingly complex, multi-step instructions.

TLDR: Instead of asking a reinforcement-learning agent to solve a complete instruction such as “find the bread, take it, go to the fridge, and place it inside” from the beginning, the proposed approach progressively teaches the required skills. The thesis evaluates five different curriculum strategies and finds that curriculum design strongly influences learning stability, task performance, generalization, and robot behavior.

Motivation and Research Problem

Future home robots need more than point-to-point navigation. They must understand what a user wants, perceive the surrounding environment, identify relevant objects and locations, and execute a sequence of actions in the correct order. A seemingly simple instruction can therefore require several tightly coupled abilities: language understanding, visual perception, navigation, object interaction, and sequential decision-making.

Standard deep reinforcement learning can struggle when an agent is exposed to the full complexity of such a task from the start. Exploration becomes difficult, useful rewards can be sparse, and the agent may fail to discover the intermediate behaviors needed to complete a long instruction. This thesis studies whether progressively structured training can make this learning process more effective.

Example target instruction
“Find the bread, take it, go to the fridge, and place the bread inside.”

Research Objectives

  • Design curriculum-learning strategies that introduce task complexity progressively, from basic navigation to object interaction and multi-step household tasks.
  • Develop an end-to-end deep reinforcement-learning framework capable of learning from visual observations and language instructions.
  • Integrate natural-language processing so that user instructions can be represented and translated into actionable robot behavior.
  • Combine curriculum learning, deep reinforcement learning, and natural-language interaction into one simulated home-robot system.
  • Evaluate learning performance through task accomplishment, generalization, scalability, and qualitative inspection of robot behavior.

Main Contributions

1. Curriculum-based Training

A staged training methodology that systematically changes task complexity so foundational robot skills can be acquired before full multi-step tasks are introduced.

2. Multi-modal Deep RL

A visual-language reinforcement-learning setup that combines RGB observations and natural-language commands for navigation and object interaction.

3. Integrated Robot Framework

A unified pipeline connecting perception, language processing, reinforcement learning, curriculum progression, and action execution inside AI2-THOR.

4. Empirical Curriculum Comparison

Five curriculum designs are experimentally compared to understand how task ordering and progression affect learning outcomes.

Proposed Multi-modal Deep Reinforcement Learning Framework

At each time step, the agent receives two main information streams: an RGB observation of the simulated environment and a natural-language instruction. The visual observation is encoded using a pre-trained ResNet-18. The textual instruction is represented using Word2Vec embeddings and processed by an LSTM. The visual and language features are fused into a joint state representation used by the reinforcement-learning policy.

RGB Observation  →  ResNet-18 Visual Encoder  ↘
Human Instruction  →  Word2Vec + LSTM Textual Encoder  →  Feature Fusion  →  MM-DQN / MM-A2C  →  Robot Action  →  AI2-THOR Environment

Two multi-modal reinforcement-learning formulations are implemented: Multi-Modal Deep Q-Network (MM-DQN) and Multi-Modal Advantage Actor-Critic (MM-A2C). The main experimental evaluation reported in the thesis focuses on MM-DQN.

The robot uses a discrete action space that includes navigation actions such as moving and turning, together with task-oriented actions such as picking up and placing objects. Positive rewards are assigned to useful progress and task completion, while collisions, redundant actions, and inefficient behavior are penalized. The reward structure can change between curriculum stages to emphasize the skill currently being learned.

[IMAGES - Thesis Figure 3.1: complete visual-language MM-DQN/MM-A2C architecture from RGB image and human instruction to robot action]

Natural Language Interaction

Natural-language commands are represented with Word2Vec and an LSTM. Longer commands are decomposed into smaller sub-instructions so that the robot can execute a sequence systematically. For example:

“Pick up the mug from the kitchen table and place it on the counter”

becomes:
identify mug → navigate to mug → pick up mug → move to destination → place mug

The embedding-based language representation also allows the system to respond to semantically similar words. In the reported robot-behavior experiments, variations such as find, locate, and identify could be used to refer to the object-search action.

Simulation Environment

Training and evaluation are performed entirely in AI2-THOR, an interactive household simulation environment. The primary training experiments use kitchen scenes, while additional experiments extend the framework to bathrooms, bedrooms, and living rooms.

AI2-THOR provides several visual modalities, including RGB, depth, instance segmentation, semantic segmentation, and surface normals. Although these modalities are available in the simulator, the learning framework in this thesis uses the RGB image as its visual input. The simulated agent can navigate through rooms and interact with household objects using actions such as finding, taking, moving toward, and placing objects.

Five Curriculum Designs

A major part of the thesis is the comparison of five ways to structure the learning progression. Each curriculum is motivated by a different assumption about how complex skills should be acquired.

Incremental Curriculum (ICL)

Complexity is increased progressively so that each new stage adds another component to the previous skill.

  1. Find the bread
  2. Find the bread, take it
  3. Find the bread, take it, go to the fridge
  4. Find the bread, take it, go to the fridge, place it inside

Reverse Curriculum (ReCL)

The robot begins from the final part of the task and progressively adds earlier sub-tasks until the complete instruction is learned.

  1. Place the bread inside
  2. Go to the fridge, place the bread inside
  3. Take it, go to the fridge, place it inside
  4. Find the bread, take it, go to the fridge, place it inside

Random Curriculum (RCL)

Training remains structured, but randomness is introduced in the objects or scenarios encountered within the curriculum.

Assumption: controlled randomness can reduce overfitting and improve adaptability.

Mastery Curriculum (MCL)

The robot focuses on mastering one complete instruction before additional complete instructions involving other objects and locations are added.

Assumption: deep mastery of one complete behavior can support transfer to new instructions.

Constructive Curriculum (CCL)

Individual skills are learned separately and then deliberately recombined into increasingly complete behaviors.

  1. Find
  2. Take
  3. Find + Take
  4. Go to location
  5. Find + Take + Go
  6. Place
  7. Find + Take + Go + Place

Why Compare Them?

The goal is not only to test whether curriculum learning helps, but also to determine how the structure of the curriculum itself affects stability, task completion, adaptability, and scalability.

Experimental Setup

The main experiments use Multi-Modal DQN in AI2-THOR. Each trial begins from a randomized robot starting position. The evaluation initially focuses on kitchen tasks and later expands to environmental variations and additional rooms.

Setting Value
Replay buffer 10,000 transitions
Batch size 64
Discount factor (γ) 0.999
Epsilon 0.90 → 0.05
Maximum training episodes 12,000
Target-network update frequency 4
Soft-update factor (τ) 1 × 10−4
Learning rate 1 × 10−4
Optimizer RMSprop
Maximum time steps per episode 200
Visual input 64 × 64 RGB

The principal evaluation criteria are learning performance, task accomplishment, generalization capability, scalability, and robot behavior.

Results

Curriculum Learning vs. Standard DRL

The baseline agent is trained directly on the full task without staged progression. In the reported learning curves, this baseline struggles to learn the complex human-instruction task. In contrast, the Incremental Curriculum agent shows clear progression as the task evolves from simple object finding toward full navigation and manipulation.

[IMAGES - Thesis Figure 5.1: baseline DRL versus Incremental Curriculum Learning curve]

Learning Curves Across Curricula

Curriculum Reported behavior at the most difficult stage
ICL Full Find + Take + Go + Place task stabilizes around 48.55 mean cumulative reward, with reduced variability.
ReCL Final full task becomes unstable and settles around −15.40, indicating difficulty when the complete task is assembled from the reverse progression.
RCL Final stage steadily improves and stabilizes near 79.00 in its learning-curve experiment.
MCL Performance deteriorates as more full instructions are added; the final stage stabilizes near −10.15.
CCL Early component skills are learned successfully, but the final combined task becomes unstable and settles near −15.00.

Based on these learning-curve experiments, the thesis selects Incremental Curriculum (ICL) and Random Curriculum (RCL) for deeper evaluation.

[IMAGES - Thesis Figures 5.2–5.6: learning curves for ICL, ReCL, RCL, MCL, and CCL]

Task Performance: ICL vs. RCL

The deeper comparison shows that the two curricula can perform similarly on some instructions, while ICL has a strong advantage on particular complex tasks. For example, during Stage 4 the reported mean cumulative rewards are:

Stage 4 Instruction ICL RCL
Find bowl → take → go to table → place 49.37 49.37
Find bread → take → go to fridge → place 49.33 49.41
Find vase → take → go to trashcan → place 48.89 17.60

The thesis additionally tests multiple random seeds. The reported seed-wise comparisons show task-dependent variability, reinforcing that curriculum effectiveness depends on both the progression strategy and the particular task structure.

[IMAGES - Thesis Figures 5.7–5.10: ICL versus RCL task-performance comparisons, including multiple random seeds]

Generalization to Environmental Changes

Generalization is tested by modifying scene illumination. Under moderate changes, the agent often retains strong performance on simpler instructions. Visually demanding tasks, however, are more sensitive to illumination changes.

Incremental Curriculum

For the bowl and bread tasks, performance remains close to the normal-condition reward under moderate lighting changes.

For the vase task, the reported reward drops from about 48.89 in normal lighting to 12.67 in a brighter environment.

Random Curriculum

RCL shows some resilience to environmental variation, but its visually demanding vase task also drops substantially under darker or brighter conditions.

Under sufficiently extreme darkness, performance for several tasks collapses, showing that the learned visual policy is not robust to all unseen conditions.

These experiments indicate that curriculum learning improves task acquisition, but curriculum alone does not solve visual domain generalization. More explicit robustness techniques are needed for large environmental shifts.

[IMAGES - Thesis Figures 5.11–5.18: ICL and RCL performance under darker and brighter scene conditions]

Scalability

The Incremental Curriculum framework is extended beyond the original three-instruction setting. With six instructions, cumulative reward stabilizes around 19.30; with nine instructions, it stabilizes near 19.95 after 12,000 epochs. The decreasing variability suggests that the agent can continue learning as the instruction set expands.

The curriculum framework is also evaluated in bathroom, bedroom, and living-room scenes with room-specific objects. The robot learns useful behaviors in all three room categories, although the living-room experiment is identified as requiring additional hyperparameter tuning.

Robot Behavior

Beyond numerical learning curves, the thesis inspects how the robot actually executes full instructions. Under ICL, the robot generally exhibits more precise and efficient behavior aligned with the target sequence. RCL can also complete tasks but is reported to occasionally produce less predictable or unnecessary actions.

Example evaluated commands include:

  • “Find the bowl, take it, go to the table, and place it there.”
  • “Locate the bread, grasp it, move to the fridge, and set it inside.”
  • “Identify the vase, collect it, proceed to the trashcan, and position it within.”

Sensitivity Analysis

The thesis studies how several training choices influence learning during Stage 2:

  • Maximum episode length: increasing the maximum number of steps from 100 toward 400 improves cumulative reward, particularly for sequential tasks that require more exploration and execution time.
  • Exploration rate: reducing epsilon from 0.90 toward 0.50 leads to faster convergence and higher cumulative rewards in several tested tasks, suggesting that excessive random exploration can slow learning after useful behavior has been acquired.
  • Reward scaling: incremental rewards for individual task components outperform normalized or heavily scaled-down rewards, providing a stronger learning signal for multi-step tasks.
[IMAGES - Thesis Figure 5.24: sensitivity analysis for maximum time, epsilon, and reward scaling]

Key Findings

1. Curriculum structure matters. Simply using curriculum learning is not enough; the ordering and decomposition of tasks strongly affect whether the agent can eventually solve the complete instruction.

2. Incremental progression fits multi-stage household instructions particularly well. Learning object finding, interaction, navigation, and placement in a progressively expanding sequence gives the agent useful foundational skills for the complete task.

3. Randomness can improve adaptability, but can also make behavior less predictable. RCL is one of the strongest alternatives and shows robustness in several experiments, while ICL generally produces more structured task execution.

4. Multi-modal state representation is effective. Combining visual features with language embeddings enables one policy to connect what the robot sees with what the user asks it to do.

5. Generalization remains an open problem. Performance degrades under extreme illumination and greater environmental variation, indicating that curriculum learning should be combined with stronger visual generalization methods.

Limitations

  • Reward design for long, multi-step tasks remains difficult; the agent can terminate prematurely or transition poorly between sub-goals.
  • Generalization degrades under extreme lighting and other unseen visual conditions.
  • Several curricula, particularly ReCL and MCL, become difficult to scale as task complexity increases.
  • Curriculum stages are manually designed and sequenced, limiting adaptability to much larger and less structured task spaces.
  • Training complex curricula requires substantial computation and restricts the number of configurations that can be explored.
  • The evaluation is simulation-based; real-world robot deployment remains future work.

Future Work

The thesis identifies several directions for extending this work:

  • Automated curriculum generation using methods such as reinforcement-learning-based curriculum optimization or self-paced learning.
  • Scaling to substantially more objects, instructions, layouts, and scenes.
  • Improving generalization using techniques such as data augmentation, domain adaptation, and adversarial training.
  • Moving from simulation toward real-world deployment in dynamic homes and offices.
  • Improving computational efficiency to support larger-scale experiments and more complex robot behaviors.

Research Takeaway

The central lesson of this thesis is that how a robot is taught can be as important as the learning algorithm itself. For multi-step home-robot tasks, exposing a reinforcement-learning agent to the complete problem immediately can make exploration and learning unnecessarily difficult. A carefully designed curriculum allows the robot to acquire reusable foundational skills and progressively compose them into more complex behavior.

The results establish curriculum learning as a promising mechanism for connecting multi-modal perception, natural-language interaction, navigation, and object manipulation in intelligent home robots, while also highlighting the remaining challenges of generalization, automatic curriculum design, scalability, and real-world transfer.
