A FEW THINGS TO KNOW

Questions?
We've got answers.

Is Glossa AI publicly available? +

Not yet. We're inviting a limited number of early users and sharing installation files individually by email.

Will I download a file immediately? +

No. The request form sends your details to our form processor, and we can reply personally when early access is available. No installer is hosted on this website.

Does the website store my email? +

This static website has no database. Your email and selected edition are processed by FormSubmit to deliver the request to our inbox. See FormSubmit's privacy policy.

Do I need an API key? +

AI-powered features currently use an OpenAI API key that you provide inside Glossa AI. Usage costs depend on your API provider and selected model.

Which languages does Glossa AI support? +

Glossa AI can help with many languages, including English, Japanese, Arabic, Chinese, and Korean. For vocabulary written in non-Latin scripts, it can also provide pronunciation guidance such as furigana, romaji, or transliteration when available. Results depend on the language, context, and selected AI model.
