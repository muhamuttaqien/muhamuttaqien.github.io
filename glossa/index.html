A FEW THINGS TO KNOW

Questions?
We've got answers.

Is Glossa AI publicly available? +

Not yet. We're inviting a limited number of early users and sharing installation files individually by email.

Will I download a file immediately? +

No. The request button prepares an email to the Glossa team. Once you send it, we can reply personally with access details. No installer is hosted on this website.

Does the website store my email? +

No. This static landing page does not store your email or submit it to a website database. You'll send it using your own email application.

Do I need an API key? +

AI-powered features currently use an OpenAI API key that you provide inside Glossa AI. Usage costs depend on your API provider and selected model.
